## Что реализовано

Python 3.12, uv, FastAPI, валидируемые настройки `APP_NAME`, `APP_ENV`,
`APP_DEBUG`, фабрика `create_app()`, строгая модель `HealthResponse`,
`GET /health`, автоматическая документация и локальные проверки.
`APP_ENV=production` остаётся меткой настройки и не включает корпоративную
авторизацию. `/health` — только liveness.

не проверяют права, историю или работу с памятью.

## Реальный HTTP-запуск

Отдельный процесс Uvicorn запущен на `127.0.0.1:8005` с настройками по умолчанию.
Запросы выполнены через HTTP, затем процесс остановлен.

| Запрос | Фактический статус |
| --- | --- |
| `GET /health` | `200`, `{"status":"ok","service":"agentic-infrastructure"}` |
| `GET /docs` | `200` |
| `GET /redoc` | `200` |
| `GET /openapi.json` | `200`, единственный прикладной путь — `/health` |
| `GET /` | `404` |
| `GET /memory` | `404` |
| `GET /agents` | `404` |
| `POST /health` | `405` |

Проверка HTML-маршрутов не означает визуальную проверку Swagger UI/ReDoc
или доступности их ресурсов CDN. Сначала ограниченная среда запрещала DNS
при установке и bind локального сокета при HTTP-проверке. После разрешённого
запуска зависимости установлены и сетевой сценарий успешно проверен.

следующих этапов, а не результаты текущих тестов. Успешный `/health`
не доказывает готовность к работе с корпоративными данными.
