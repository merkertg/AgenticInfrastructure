## Реализованная граница этапа 05

Добавлен доверенный приём документов одного формата: UTF-8 текст до 64 КиБ
и 20 000 символов, без управляющих символов, кроме табуляции и перевода строки.
Пакет до 50 файлов проверяется целиком до записи и принимается или отклоняется
полностью со списком кодов. Версия делится на фрагменты-абзацы до 800 символов;
смещения `start`/`end` воспроизводят текст фрагмента.

Маршрут `POST /memory/projects/{project_id}/context` выполняет поиск одной
транзакцией под блокировкой компании. Сначала проверяются токен и область
проекта (`evaluate_scope()`), затем каждый документ (`evaluate_access()`).
Текст загружается только для разрешённых версий, статистика BM25 считается
только по их фрагментам, выбранные документы проверяются ещё раз перед ответом.
Индекс и кэш не хранятся. Пустой результат возвращается явно как
`no_authorized_evidence`, отказ области — единым `404`. История хранит
ссылки и SHA-256 запроса без текста.

## Что ещё отсутствует

Нет семантического и векторного поиска, сохранённого индекса, кэша, приёма
и удаления документов по HTTP, инструмента агента, модели, корпоративного
поставщика личности, TLS, ограничения частоты, корпоративного коннектора
и контейнерного выпуска. Лексический BM25 находит только совпадающие слова.
Каждый поиск заново читает разрешённые версии. Владелец БД может напрямую
изменить документы, права, токены и историю. Временный локальный кластер
не является развёрнутым сервисом. Следующий этап — ограниченный инструмент
контекста для агента.
